# 114 Songs

A digitization of Charles Ives's 114 songs using [MuseScore Studio](https://musescore.org)

You can browse the selection ones at [MuseScore.com](https://musescore.com/user/95184583/sets/13552957) though do note that many of these songs are outdated and do not reflect the newest version avaliable here.

The songs are all in the public domain and the original volume is avaliable for viewing at [Harvard.](https://viewer.lib.harvard.edu/viewer/URN-3:FHCL.LOEB:1199027?n=1)
